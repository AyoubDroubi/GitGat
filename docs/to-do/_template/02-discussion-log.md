# 02 — Discussion Log

Append-only record of meaningful product comments.

## Entry format

### DL-NNN — YYYY-MM-DD HH:MM — actor/source

**Comment:** Concise summary of the meaningful comment.  
**Impact:** What this changes or clarifies.  
**Affected requirements:** REQ-NNN / none.  
**Affected baseline:** vN / none.  
**Linked decision:** D-NNN / none.  
**Status/track/health impact:** none / describe.

Do not paste raw transcripts unless exact wording is itself required evidence.
